# Pleos App Market 심사 체크리스트 (LLM wiki)

원문: document.pleos.ai (Pleos Connect). 아래 규칙은 원문에서 그대로 옮긴 것임. **[반려]** = 원문이 "거부/반려/즉시 거부/통과할 수 없음"이라고 명시했거나 흔한 반려 원인으로 보이는 항목.

## TL;DR — 꼭 지킬 규칙
1. **미디어 앱(동영상·게임·브라우저)은 주행 중 실행/사용 불가** — 운전 시작 시 일시정지 + UI 숨김, 주행 중 '일시 중지' 해제 불가. 헤드업 알림 금지.
2. **성능 수치**: 실행 10초 이내, 콘텐츠 로드 10초 이내, 버튼 반응 2초 이내(넘으면 로딩 UI 표시), 터치→터치효과 응답 0.25초 이내.
3. **Vehicle SDK 퍼미션은 App Market 사전 협의·승인된 것만 선언** — 미승인 퍼미션 선언 시 심사 통과 불가.
4. **심사 요청마다 앱 버전 변경 필수**(미변경 시 반려). APK만, 최대 600MB. 자동 업데이트 없음 → 앱이 직접 버전체크+`market://detail?package={패키지명}` 이동 구현.
5. **배포 빌드**: 정식 배포 서명 인증서, 디버깅/디버그 빌드 설정/WebView 원격 디버깅 비활성화, 로그에 민감정보 금지, 키 하드코딩 금지(Android Keystore), TLS 1.2+.
6. **레터박스 없이 화면 채우기**(한 방향 미세 레터박스만 허용), 호환성 모드 실행 금지, 해상도 전환 시 상태 손실/기능 변화 없음.
7. **백그라운드 복귀 시 마지막 상태 복원**(수 시간 이상 미사용 시만 기본 상태 허용). 테스트 더미 데이터/임시 콘텐츠 금지.
8. 로그인 앱은 **실사용자 기준 전체 권한 계정** 제출. 개인정보/위치정보 사용 시 개인정보처리방침(+위치정보 이용약관) URL, 명시적 동의 UI(동의 버튼 외 동작을 동의로 간주 금지).

## 1. Pleos App Market 등록정보 (메타데이터)
- [ ] 기본 정보(앱 이름, 설명, 개발자 이름, 아이콘, 이미지 등) 정확히 입력.
- [ ] 기본 정보에 욕설/폭언/폭력·선정적 묘사/범죄·불법(약물, 테러 등) 묘사 없음.
- [ ] App Market 실적·순위·매출 등 사실 확인이 힘든 내용 없음.
- [ ] 텍스트 이모티콘, 반복되는 특수문자 사용 금지.
- [ ] 제목/아이콘: 타 앱과 유사·중복·오해 소지 없음. **앱 제목 30자(영문 기준) 이하**.
- [ ] 서비스 대상 국가별 언어로 모든 메타데이터 제출.
- [ ] 가장 적합한 카테고리 선택(부적합 시 임의 변경될 수 있음). **[반려]** 카테고리와 벗어나는 기능/상이한 유형 선택 시 제출 거부 가능.
- [ ] 앱 아이콘: **최대 1 MB, 512 x 512 px, PNG 또는 JPEG**.
- [ ] 앱 이미지(IVI 스크린샷): **최소 2장, 최대 8장**, 1장당 최대 8 MB, PNG/JPEG, 해상도 **2560 x 1380 / 1700 x 1212 / 840 x 1212 px** (제출 항목 표에는 "840 x 121 px"로 오기되어 있음). 업로드 순서대로 슬라이드. 예: 기능 사용 전/후/앱만의 기능 화면.
- [ ] **[반려]** 제출 아이콘·이미지가 실제 앱과 다르면 심사 거부 가능.
- [ ] 패키지: **APK**, 압축된 다운로드 최대 크기 600MB 미만.
- [ ] 연령 등급은 콘텐츠에 적절히(설문에 정직하게).
- [ ] 개인정보 처리 과정(수집, 이용, 저장, 파기, 생성, 연계, 전송), 접근 권한(카메라, 저장 공간, 마이크, GPS, 전화, 연락처 등), 위치정보 서비스·광고성 정보 전송 여부를 정직하게 선택/입력.
- [ ] 개인정보처리방침 등록(앱 전용 없으면 회사 공통 방침 가능). 위치정보 사용 시 '위치정보 이용약관 및 기타 정보 처리방침' 함께 제출.
- [ ] **[반려 주요 원인]** 로그인 필요 시 심사용 계정 제출: 관리자 계정 X, **실제 사용자 기준 계정**; 게스트 계정 가능해도 일반 사용자 계정 제출; 웹 앱도 연결 페이지 사용 가능 계정.
- [ ] 메타데이터 악용으로 사용자 기만 시 즉시 제외 + 영구 제재 가능.

**증빙 서류 (해당 시)**
- [ ] 타사 지적재산권(브랜드 이름, 웹사이트, 로고, 오디오/이미지 저작물) 사용 권리 증빙.
- [ ] 정부/정부기관 대신 제작·허가 앱 → 증명 서류(관련 정부기관이 제출).
- [ ] 웹 앱 등 웹페이지 연결 앱 → 도메인 등록 증빙(호스팅 업체 발급 도메인 등록 확인증).
- [ ] 공인 의료기관 앱 배포 권한 증빙.
- [ ] 대한민국 성인용 게임물 → 게임물관리위원회(GRAC) 심의 등급 결과 및 증빙.

## 2. 콘텐츠 안전성
- [ ] 미디어 콘텐츠 포함 앱 → 서비스 국가/지역 심의(연령등급) 받기.
- [ ] **[반려]** 미디어 중계 플랫폼(OTT, 웹툰 등)·사용자 생성 콘텐츠(UGC)·**AI 생성 콘텐츠** 앱 → 부적절 콘텐츠 **필터링 기능 + 신고 채널** 필수.
- 예외: 공익 목적 또는 ESDA(교육, 과학, 다큐멘터리, 예술) 목적이면 허가될 수 있음.
- [ ] 안전 저해 금지: 음주 운전, 과속, 신호 위반 등 권유·조장·홍보·미화 금지. 주류 광고는 현지 광고법 준수 + 음주운전 위험 경고 포함.
- [ ] 선정적 콘텐츠(과도한 노출, 포르노, 성적 서비스, 성매매 주선·홍보) 금지 → 거부.
- [ ] 폭력(폭행, 유혈, 테러) 조장·미화, 과도한 욕설·폭언 금지.
- [ ] 위험 콘텐츠: 자살·자해 조장 거부. **아동이 차량 밖으로 신체 일부를 내밀도록 유도하는 콘텐츠 거부**.
- [ ] 불법: 범죄 조장/알선, 테러·약물·무기·인신매매 권유 금지.
- [ ] 사행성: 실제 금전 도박/불법 도박 조장·경로 제공 금지.
- [ ] 차별(인종, 종교, 성별 등), 민감 사건(재난, 사고, 전쟁, 갈등, 전염병) 악용 금지.
- [ ] 승인되지 않은 물품(미승인 식/약품, 의료기구, 처방전 없는 처방약) 홍보/판매 금지.
- [ ] 아동 학대·착취·성적 목적 콘텐츠 엄격 금지. 아동 관심 유도 + 성인용 주제(잔인, 위험 활동, 노출) 앱 금지.
- [ ] 미성년자 보호: 인증 없이 보이는 화면·미리보기·썸네일·인앱 스크린샷·상품 사진엔 **'전체 이용가'** 콘텐츠만.
- [ ] 연령 등급 설문 정직하게. 부여 등급에 부적절 콘텐츠 확인 시 제한·신고. 영화·음악·게임 등은 현지 요건 준수.
- [ ] 지적재산권(상표, 저작권, 특허) 무단 사용·위조품 판매 금지. 신고되면 다운로드 차단 → 기간 내 소명 못하면 영구 제외.
- [ ] **[반려]** 암호화폐 채굴 앱 거부.
- [ ] 루트 박스/확률형 아이템 → 구입 전 각 항목 수령 확률 공개.

## 3. 운전자 주의 분산 요소 최소화
- [ ] Pleos Connect UI Design Guide(`connect/guide/docs-design/...`) 사전 확인 필수. 가이드 준수해도 추가 위험 판단 시 거부 가능.
- [ ] **[반려]** 미디어 앱(= 동영상, 게임, 브라우저 기능 앱)은 **정차 중에만 사용 가능**, 운전 중 실행/사용 불가.
- [ ] **[반려]** 운전 시작 시 사용 일시 중지 + **앱 UI 숨김**. 운전 중 동영상·게임·브라우저 '일시 중지' 해제 불가.
- [ ] 백그라운드 → 복귀 시 마지막 상태 복원(수 분 이내 복귀: 최대한 가깝게, 수 시간 이상: 마지막 또는 기본 상태 가능).
- [ ] 모든 미디어 항목에 한눈에 들어오는 제목·썸네일, 부적절 내용 없음.
- [ ] **미디어 앱은 헤드업 알림 게시 금지**, 운전과 무관한 알림 사용 불가.
- [ ] 동영상 앱은 **미디어 세션과 통합**. 여러 미디어 동시 사용 불가. 재생/일시정지/중지 명령 지원.
- [ ] 브라우저 앱: 비밀번호/결제 정보 저장·접근 허용 금지(프로필 잠금으로 차단 가능한 경우만 예외). 동기화 시 사전에 인증 메시지 표시 + 차 화면에 "데이터가 자동차와 동기화된다"고 고지.

## 4. 기능 · 성능 · 안정성
**완성도**
- [ ] **[반려]** 설치/삭제 오류 없음(인증 키 누락으로 미설치, 파일 누락, 삭제 후 아이콘/파일 잔존).
- [ ] **[반려]** 실행 오류 없음(강제 종료, 하드웨어 재시작).
- [ ] 기능 오류 없음(화면 멈춤, 기능 미동작, 터치 미인식). 미디어 출력 정상(사운드 끊김, 그래픽 깨짐 없음).
- [ ] **[반려]** 제출 앱 = 실제 서비스 앱. 테스트 더미 데이터/임시 파일/임시 콘텐츠 금지.
- [ ] UI 요소 왜곡·흐림·모자이크 없음. 디스플레이 컷아웃, 인셋, 소프트웨어 키보드, 시스템 표시줄 등 **기기 안전 영역 준수**(UI 세이프티 존, 입력 방법, 자막, 탐색 메뉴 고려).

**기능 및 성능 (수치)**
- [ ] 심각한 성능 저하(스터터링, 프레임 저하, 화면 끊김) 없음. 앱 과점유로 시스템 성능 저하 없음.
- [ ] **입력 후 차량 시스템 응답 시간 ≤ 0.25초** (터치 → 터치 효과 애니메이션 발생까지).
- [ ] **앱 실행 ≤ 10초, 콘텐츠 로드 ≤ 10초, 특정 버튼 반응 ≤ 2초** (반응 = 화면 전환/기능 동작/상태 변화).
- [ ] 2초 내 버튼 동작/로드 못하면 UI로 동작 중임을 표시.
- [ ] 백그라운드 복귀 시 마지막 상태 복원(수 시간 이상 미사용 시만 기본 상태).
- 성능 기준 상세: `pleos-only/vehicle-app-planning-guide/performance-resource-mgmt` (메모리·CPU·배터리).

**HW/SW 손상**
- [ ] HW/SW 손상, 과점유 성능 저하 금지. 사용자에게 기기 재시작이나 핵심 기능과 무관한 시스템 설정 변경 제안·요구 금지.

**SDK·API 사용 심사**
- [ ] Vehicle SDK API 사용 시 필요한 퍼미션을 앱에 선언.
- [ ] **[반려]** Vehicle SDK 퍼미션은 Pleos App Market과 **사전 협의 및 승인**된 경우만 선언 가능. 미승인 퍼미션 선언 앱은 심사 통과 불가. (제출 시 "SDK 추가 권한" 항목에 My Project > 프로젝트 정보 > 프로젝트 ID 입력)

**디스플레이 호환성** (상세: `connect/guide/docs-design/getting-started/layout`)
- [ ] **[반려 주요 원인]** 레터박스 없이 디스플레이 최대한 채움(한 방향 미세 레터박스만 허용). **호환성 모드 실행 금지**.
- [ ] 해상도 전환 중 상태 손실·화면 이상(이미지 늘어짐, 앨리어싱/블러, 터치 영역-버튼 위치 불일치) 없음.
- [ ] 모든 화면 상태/전환에서 동일 기능 노출(기능 패리티). 버튼/기능 바뀌지 않고 비율에 맞게 이동.

## 5. 사용자 개인정보 및 보안
**개인정보**
- [ ] 접근권한 서비스 필요 범위로 최소화.
- [ ] 법적 고지(수집 항목, 처리목적, 보유기간, 동의 거부 권리) + **명시적 동의 절차** 구현. 목적 외 사용 금지.
- [ ] 개인정보 처리방침 공개, 열람청구권 등 권리 보장(그 외 GDPR 등 국가별 법령).
- [ ] 위치정보 서비스 → 등록/신고 확인 요청 가능, 미확인/허위 시 판매 중단.
- [ ] 투명성: 수집 데이터 목록·사용 방식·공유를 **앱 자체에서** 명시.
- [ ] 개인정보 수집/사용 약관 또는 법률 준수 증빙을 App Market에 제출.
- [ ] 아동 개인정보 → 수집 전 법정 대리인 고지 + 명시적 동의.
- [ ] **[반려]** 동의/거부 UI는 명확해야 함. **동의 버튼 외 행동(뒤로가기, 빈 공간 터치)을 동의로 간주 금지**. 허가된 항목 데이터만 접근.
- [ ] 맞춤형 광고는 개인정보 활용·제3자 제공 동의를 통해서만. 사용자가 철회 가능해야 하고, 철회 시 즉시 활용 경로 차단 + 저장 데이터 삭제.

**보안 (즉시 거부 가능)**
- [ ] **[반려]** 기기/프로그램/데이터 손상·교란·변조, 동의 없는 다른 코드/프로그램 설치 → 즉시 거부.
- [ ] **[반려]** 시스템 보안 보호 기능 우회/무력화 → 즉시 거부.
- [ ] 바이러스, 스파이웨어, 트로이 목마, 애드웨어, 루팅, 스팸, DDoS, 크립토재킹, 피싱, 사기광고 금지.
- [ ] SDK 악용·사용자 데이터 무단 활용 엄격 금지.

## 6. 심사 제출 전 준비 사항
- [ ] 개발자 정보 최신화, 특히 **연락처는 심사팀이 언제든 연락 가능**해야 함.
- [ ] 기능 테스트: 실행 불가, 크래시, 성능 저하, 버그, 이미지 깨짐, 해상도 늘어짐. 과부하·배터리 소모 주의.
- [ ] 보안 취약점·멀웨어 확인(→ 7.1 앱 보안 가이드).
- [ ] 메타데이터(앱 명칭, 버전명, 카테고리 / 출시 국가, 연령 등급, 접근 권한, 개인정보 처리 / APK, 아이콘, 스크린샷 / 약관·처리방침) 확인.
- [ ] 모든 기능·콘텐츠 접근 활성화 계정 제공.
- [ ] **외부 서버 연동 앱은 제출 전 운영 구성요소 미리 활성화**(심사 중 즉시 연결 가능하도록).
- [ ] 운전자 주의 분산 설계 확인(`pleos-only/vehicle-app-planning-guide/driver-distraction-guideline`).
- [ ] 출시 국가 법률·규제 준수, 판매/홍보 제품(식약품, 의료기기 등) 허용 증빙 제출.
- [ ] 연령 등급: App Market은 **IARC**와 연계 → IARC 심의 받고 **등급 증적 제출**. 한국 게임은 게임물관리위원회 심의.
- [ ] 설명 필요한 기능은 **심사 노트**에 주석 + 기능 사용 설명서 첨부.

## 8. 등록 요건

### 8.1 앱 보안 가이드 (미준수 시 심사 통과 못할 수 있음)
**민감 데이터**
- [ ] 기기 저장 민감정보는 위치 무관 **암호화**(내/외부 저장소, 캐시, SQLite, SharedPreferences). 암호화 중 임시파일/사본에 평문 금지.
- [ ] **릴리스 전 디버그 로그 비활성화 또는 민감정보 마스킹**.
- [ ] 민감정보 캐시 저장 지양(필요 시 암호화), 사용 끝난 캐시·임시파일 삭제.
- [ ] 자동 백업: non-GAS AAOS라 Google 자동 백업 미동작이지만 **사용 안 하면 비활성화 권장**(`android:allowBackup` 등), 사용 시 민감 파일 제외.
- [ ] 민감정보는 앱 전용 내부 저장소. 외부 저장소면 암호화.
- [ ] **토큰/세션/비밀번호를 URL 경로·쿼리에 넣지 말 것** → Authorization 헤더.

**암호화**
- [ ] 해시: MD5, SHA-1 대신 SHA-256. 블록 모드: **AES-GCM** 권장, **ECB 금지**. RSA는 SHA-256 OAEP 패딩.
- [ ] AES-GCM에서 동일 키로 IV/nonce 재사용 금지. 암호학적으로 안전한 난수 생성기(SecureRandom) 사용.
- [ ] **키는 Android Keystore**로 관리. 소스/리소스/설정 파일 하드코딩 금지, 데이터와 함께 평문 저장 금지.

**통신**
- [ ] HTTPS 등 암호화 프로토콜. **TLS 1.2 이상 필수, 1.3 권장**. SSL, TLS 1.0/1.1 연결 차단. 안전한 Cipher Suite.
- [ ] 신뢰할 수 있는 서버만, 기능과 무관한 서버와 통신 금지. 서버 원격 명령은 출처·유효성·무결성 확인 + 범위 제한.

**컴포넌트/권한**
- [ ] 필요한 권한만(여러 환경 공용 앱도 Pleos Connect 기준).
- [ ] 외부 호출 불필요한 Activity/Service/BroadcastReceiver/ContentProvider는 비노출(`android:exported="false"`).
- [ ] 민감정보 전달 시 수신 대상 명시, 암시적 브로드캐스트 금지. 공개 컴포넌트는 호출자 인증 + 접근 권한 둘 다 확인.
- [ ] WebView 로컬 파일 접근 최소화/불필요 시 비활성화. 외부 URI/파일 경로 검증·정규화.

**개발/배포**
- [ ] Pleos 공식 제공·허용 API만, 기능 관련 차량 API만 사용.
- [ ] 토큰·비밀 키 하드코딩 금지. 서버 IP 하드코딩 대신 도메인.
- [ ] 네이티브 라이브러리 RELRO, Stack Canary, NX 권장. SDK/라이브러리 취약점 패치 유지.
- [ ] **[반려]** 정식 **배포용 서명 인증서**(디버그 인증서 금지).
- [ ] **[반려]** 최종 앱에서 **앱 디버깅(`debuggable`), 디버그 빌드 설정, WebView 원격 디버깅 비활성화**.

**WebView/브라우저**
- [ ] WebView 로드 콘텐츠·이동 사이트 범위 제한, JavaScript/JS 브리지는 필요할 때만.
- [ ] 브라우저 앱: 보안 업데이트 지원 엔진만, HTTP→HTTPS 자동 전환 + 비암호화 경고, 인증서 검증 우회 금지(신뢰체인·유효기간·호스트명), SOP/CORS 준수, **CSP Level 2 이상**, 샌드박스 유지, 개발자 모드·임의 프록시·확장 프로그램 설치 비활성화, **파일 다운로드 제한**, 악성 사이트 차단 권장.

### 8.2 앱 태그 표기 (외국어 원문 타이틀 앱)
- [ ] **[반려]** 공식 타이틀이 외국어면 한국어로 노출되더라도 **원문(영문) 앱명을 태그로 반드시 추가**, 공식명과 동일 표기(축약·변형 금지).
- [ ] 한국어 태그는 선택. 다국어 타이틀이면 각 언어 명칭 추가 가능하나 영문 태그 필수.
- 예: 공식명 Sport / 노출 스포츠 → 필수 태그 `Sport`, 선택 `스포츠, 운동`.

`raw/pleos-only/app-registration-guide/app-tagging-guide.md`

### 8.3 앱 업데이트 (자동 업데이트 미지원)
1. 앱 실행 시 최신 버전 확인(개발사 구현; SDK 제공은 차후 고려).
2. 구버전이면 팝업: `최신 버전이 존재합니다. 업데이트를 위해 페이지를 이동할까요? (Yes, No)` (개발사 구현).
3. Yes → 앱 상세 페이지 `market://detail?package={패키지명}` 이동 (개발사 구현).
4. 앱 마켓이 로그인 확인: 미로그인 → 로그인 창 후 마지막 페이지/홈으로 이동하고 종료; 로그인 → 상세 페이지 **[업데이트]** 버튼 (마켓 제공).
5. No → 개발사 정책에 따라 사용 유지 또는 종료 (개발사 구현).
6. 최신이면 그대로 실행.

`raw/pleos-only/app-registration-guide/app-update-guide.md`

## 9. 개발 가이드에 있는 카테고리별 심사 기준 (상세는 `wiki/dev-guide.md`)
- [ ] **[반려]** 최상위 화면에서 CCP Back(표준 Back) 입력 시 앱 종료 또는 `moveTaskToBack(true)` 숨김 미구현 → 반려 대상. `finish()`/`finishAffinity()` 금지.
- [ ] CCP 미지원 User-installed 앱: 필수 조작을 터치만으로 완결 + `com.hmg.rotary.ROTARY_SUPPORTED=false` 선언.
- [ ] **Music/Audio**: 오디오 재생이 주 기능(보조 기능 음악 앱은 **즉시 반려**), `MediaBrowserService` + `MediaSession` 필수(미구현 시 배포 제외), 스티어링 휠 키(재생/일시정지/정지/미디어 ID 재생/검색 재생) 미구현 시 반려 가능, 하위 카테고리(음악/팟캐스트/오디오북/라디오) 불명확 시 반려 사유, 자동 재생 금지.
- [ ] **Maps/Navigation Immediate Reject**: 주행 중 광고, 영상·게임 요소, 복수 내비 동시 경로 안내, 카테고리 위반 기능(`APP_MAPS` 선언과 등록 카테고리 불일치), OEM/AAOS 정책 위반. 불필요 권한, crash/freeze, 주행 중 전체 화면 팝업 금지.
