# Spinner

#### Drag를 통해 여러 옵션 중 하나를 선택할 수 있는 기능을 제공할 수 있습니다.

![Picker1.svg](https://document.pleos.ai/assets/images/Picker1-58af05a862c1abc9f94795bff7e2dea1.svg)

**1. Root** : 컴포넌트를 감싸는 최상위 컨테이너 영역   
**2. Selection Value** :현재 선택된 value를 보여주는 영역   
**3. Contents** : 선택 가능한 value가 나열되어 보여지는 영역

  

## Properties

| Type | Description |
| --- | --- |
| Date | 날짜를 기반으로 선택 가능 |
| Time | 시간을 기반으로 선택 가능 |
