# Colors

Color는 하나의 제품으로써 브랜드 아이덴티티를 유지하기 위한 도구이자, 고객의 혼란을 최소화 하기 위해 색상 대비를 통해 소프트웨어 내에서 명확한 정보의 위계를 표현할 수 있어야 합니다.

> 업데이트 구분
> 🟠 기존 업데이트
> 🔵 신규 추가

---

## Basic Color

Scale Token은 프로덕트의 일관된 색상 체계를 정의하는 표준화된 컬러 토큰입니다. 특별한 시맨틱한 성격이나 맥락을 갖고있지 않은 경우에 사용하며, 그 어떤 경우에도 Scale Token을 사용할 수 있습니다.

### Grayscale

가장 기본적인 흑백 컬러로 투명도가 없는 색상입니다.

![Color1](https://document.pleos.ai/assets/images/grayscale-f6be0c4273c5777035ffd84ea28013c9.png)

### Alpha Color​

투명도를 가진 색상으로, 컬러의 투명도를 조절하여 주로 배경이나 다른 요소들과 조합에 사용됩니다.

#### White Alpha

![Color2](https://document.pleos.ai/assets/images/white-alpha-1a1359524cb98282c87149651de538d8.png)

#### Gray Alpha

![Color3](https://document.pleos.ai/assets/images/gray-alpha-0ce361ac45bdc95d66fc57411cf28ae6.png)

### Static Color

라이트, 다크 테마에 영향을 받지 않으며, 항상 raw값을 유지하는 컬러입니다. 주로 Overlay 위에 올라가는 요소에 사용됩니다.

#### Light

![Color4](https://document.pleos.ai/assets/images/light-0b540b02ca3f98e2cd94205da112ef67.png)

#### Dark

![Color5](https://document.pleos.ai/assets/images/dark-f44c562ac0ca05f9ccbda030142cf5e0.png)
